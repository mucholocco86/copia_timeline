# 2 — URM X52 convertido

Coloque aqui **exatamente o conteúdo da pasta `2_URM_X52_CONVERTIDO/` do pacote `MOD_ANALISE`**.

Esta área preserva os artefatos convertidos/gerados durante o processo de análise, incluindo os `.rpy` utilizados para inspeção técnica.

## Regras

- Preservar a estrutura interna da pasta do pacote.
- Não tratar os `.rpy` convertidos como se fossem o código-fonte distribuído originalmente.
- Não misturar este conteúdo com `1_URM_ORIGINAL/`.
- Alterações interpretativas e conclusões devem ficar na documentação de `URM_REVERSO/`.

Esta pasta existe para permitir o cruzamento direto entre o material analisável, a engenharia documentada e o SDK Ren'Py 7.4.11.
